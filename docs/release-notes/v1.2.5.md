# v1.2.5 — 一句话发版（首个公开 Release）

DeepSeek Harness（DSH）服务器部署插件：在会话里说「部署到 test/uat/prod」，自动完成 **构建 → 上传 → 备份 → 停服 → 替换文件 / 解压前端 → 启服 → 健康检查**，全过程实时投影到侧边栏终端。支持**单机、前端、微服务、集群**四种部署形态，环境名自由。

npm 同版本：[`dsh-server-deploy@1.2.5`](https://www.npmjs.com/package/dsh-server-deploy)

---

## ✨ 亮点

### 1. 四种部署形态 + 模板生成（1.1.0）

`deploy_config init` 支持 `template` 参数，按形态一键生成配置骨架：

| 形态 | template | 关键配置 |
| --- | --- | --- |
| 单机后端 | `single` | `type: "backend"` + `artifacts` |
| 前端 | `frontend` | `type: "frontend"` + `package.local`（dist 打 zip 上传解压） |
| 微服务 | `services` | `services: [...]`，每服务独立服务器/构建/健康检查，`parallel` 并发 |
| 集群 | `cluster` | 服务配 `instances: [...]`，构建共享一份、逐台部署 |

### 2. 密钥认证默认 + 自动发现（1.2.0）

模板与缺省认证改为密钥优先：`auth.type = "key"` 不填 `privateKey` 时自动找 `~/.ssh/id_ed25519` → `id_ecdsa` → `id_rsa` → SSH agent；找不到时给出可照做的报错（生成密钥 / 改密码认证 / 指定路径）。密码认证全程可用，且环境 → 服务 → 实例三层均可覆盖。

### 3. 模型看得见部署输出（1.0.12+）

- 工具结果带 `outputTail`（终端同一份日志的最后 2000 字符），失败不用用户贴日志
- DSH 0.2.2+ 走 **Agent 终端**（`openForAgent`：Host 自己开终端、输入跟随命令、跑在会话沙箱内），旧版自动回退浏览器驱动路径

### 4. 缺配置必须问，不猜（1.1.1+）

配置存在但缺字段时报错点名具体字段（`environment.remote.deployDir is required`、`service "api" needs remote.deployDir …`）；提示词要求把缺失项转述给用户、用 `deploy_config update` 补齐再重试，绝不编造服务器地址或路径。

### 5. 设置页「应用部署」（1.2.3–1.2.5）

设置中新增一页：版本号 + 一句话说明 + npm 累计下载（打开自动拉取，网络失败不显示）+ GitHub 图标。被 DSH 官方插件详情页内嵌时自动精简为标题 + 说明一行。

## 📦 安装 / 升级

```powershell
dsh plugin --profile web add dsh-server-deploy@1.2.5
# 已安装：插件页 → 已安装 → 应用部署 → 更新
```

要求 DSH `>= 0.2.2-0 < 0.3.0`；安装/升级后**重启 dsh web**。
